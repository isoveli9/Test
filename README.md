## Vastaukset lyhyesti

**Tehtävä 1**, r(p) = −3p² + 6p − 2
- a) Nollakohdat p = 1 ∓ √3/3, joten myynti on kannattavaa välillä **[0.423, 1.577]**
- b) r′(p) = −6p + 6 = 0, joten p = 1 ja suurin voitto on **r(1) = 1**
- c, d) Excel: kaavat ja taulukko (MAX, MINIFS/MAXIFS) antavat samat tulokset, ja kuvaaja vahvistaa ne

**Tehtävä 2**, p(t) = 54.99 · 1.0249ᵗ
- a) 2015 (t = 7): **65.32 $**, 2025 (t = 17): **83.54 $**
- b, c) Excel: hintataulukko vuosille 2008–2025 ja kehityskäyrä

**Tehtävä 3**
- a) (1/2)^(t/1600) = 0.67, josta t = 1600 · ln 0.67 / ln 0.5 ≈ 924.4 vuotta, eli **vuonna 2878**
- b) 1.0249ᵗ = 100/54.99, josta t = ln(1.8185)/ln(1.0249) ≈ 24.31 vuotta, eli **vuonna 2032** (kokonaisina vuosina hinta ylittää 100 ensimmäisen kerran vuonna 2033)

**Tehtävä 4**
- a) 76 − 71.7 = **4.3 prosenttiyksikköä**
- b) 4.3 / 71.7 ≈ **+6.0 %**
- c) −0.2 / 71.7 ≈ **−0.28 %** (lasku 0.28 %)
